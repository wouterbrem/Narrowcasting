# Auto-Update Setup with electron-updater

This document explains how to implement automatic updates for Narrowcast Pro using `electron-updater`.

## Status: Partially Implemented

The groundwork has been laid, but auto-updates require a server or GitHub releases to host update files.

---

## What is electron-updater?

`electron-updater` allows your Electron app to automatically check for and download updates without requiring users to manually download new versions.

## Installation

```bash
npm install electron-updater
```

**Already added to package.json** but you'll need to run `npm install` to install it.

---

## Implementation Steps

### 1. Update electron/main.js

Add the following at the top of `electron/main.js`:

```javascript
const { autoUpdater } = require('electron-updater');
const log = require('electron-log');

// Configure logging for updates
autoUpdater.logger = log;
autoUpdater.logger.transports.file.level = 'info';
log.info('App starting...');

// Auto-update settings
autoUpdater.autoDownload = false; // Don't auto-download, ask user first
autoUpdater.autoInstallOnAppQuit = true;
```

### 2. Add Update Event Handlers

After `app.on('ready', ...)` add:

```javascript
// Check for updates when app is ready
app.on('ready', () => {
  startServer();
  setTimeout(createWindow, SERVER_STARTUP_DELAY);

  // Check for updates (after a delay to not slow down startup)
  setTimeout(() => {
    autoUpdater.checkForUpdates();
  }, 10000); // Check after 10 seconds
});

// Auto-updater events
autoUpdater.on('checking-for-update', () => {
  log.info('Checking for update...');
});

autoUpdater.on('update-available', (info) => {
  log.info('Update available:', info);

  // Show dialog to user
  dialog.showMessageBox(mainWindow, {
    type: 'info',
    title: 'Update Available',
    message: `A new version (${info.version}) is available!`,
    detail: 'Would you like to download it now? The update will be installed when you quit the app.',
    buttons: ['Download', 'Later'],
    defaultId: 0
  }).then((result) => {
    if (result.response === 0) {
      autoUpdater.downloadUpdate();
    }
  });
});

autoUpdater.on('update-not-available', (info) => {
  log.info('Update not available.');
});

autoUpdater.on('error', (err) => {
  log.error('Error in auto-updater:', err);
});

autoUpdater.on('download-progress', (progressObj) => {
  let logMessage = `Download speed: ${progressObj.bytesPerSecond}`;
  logMessage += ` - Downloaded ${progressObj.percent}%`;
  logMessage += ` (${progressObj.transferred}/${progressObj.total})`;
  log.info(logMessage);

  // Optional: Show progress in window
  if (mainWindow) {
    mainWindow.setProgressBar(progressObj.percent / 100);
  }
});

autoUpdater.on('update-downloaded', (info) => {
  log.info('Update downloaded');

  dialog.showMessageBox(mainWindow, {
    type: 'info',
    title: 'Update Ready',
    message: 'Update downloaded successfully!',
    detail: 'The update will be installed when you quit the app. Restart now?',
    buttons: ['Restart', 'Later'],
    defaultId: 0
  }).then((result) => {
    if (result.response === 0) {
      autoUpdater.quitAndInstall(false, true);
    }
  });
});
```

In `createMenu()`, add to the Help menu:

## Update Server Options

You need a server to host update files. Choose one:

### Option 1: GitHub Releases (Free, Recommended)

1. Push code to GitHub
2. Create a new release with tag (e.g., `v2.2.0`)
3. Attach your build files:
   - `Narrowcast-Pro-2.2.0.dmg` (Mac)
   - `Narrowcast-Pro-2.2.0.dmg.blockmap` (generated by electron-builder)
   - `Narrowcast-Pro-Setup-2.2.0.exe` (Windows)
   - `Narrowcast-Pro-Setup-2.2.0.exe.blockmap`
   - `latest-mac.yml` (generated by electron-builder)
   - `latest.yml` (for Windows, generated by electron-builder)

4. Update package.json:
```json
{
  "build": {
    "publish": [
      {
        "provider": "github",
        "owner": "YOUR_USERNAME",
        "repo": "Narrowcasting"
      }
    ]
  }
}
```

5. Set GitHub token as environment variable:
```bash
export GH_TOKEN="your_github_personal_access_token"
npm run dist:mac
```

### Option 2: Self-Hosted Server

1. Set up a web server (e.g., Nginx)
2. Create update manifest files
3. Update package.json:
```json
{
  "build": {
    "publish": [
      {
        "provider": "generic",
        "url": "https://your-domain.com/updates"
      }
    ]
  }
}
```

### Option 3: AWS S3

```json
{
  "build": {
    "publish": [
      {
        "provider": "s3",
        "bucket": "your-bucket-name",
        "region": "us-east-1"
      }
    ]
  }
}
```

## Building with Auto-Update

```bash
# Set your GitHub token (or other provider credentials)
export GH_TOKEN="ghp_xxxxxxxxxxxxx"

# Build and publish
npm run dist:mac -- --publish=always
npm run dist:win -- --publish=always
```

This will:
1. Build the app
2. Generate update manifests (latest-mac.yml, latest.yml)
3. Upload to your configured provider

## Testing Updates

### Local Testing

1. Build version 2.1.0:
```bash
npm version 2.1.0
npm run dist:mac
```

2. Install and run it

3. Increment version:
```bash
npm version 2.1.1
```

4. Build and publish:
```bash
npm run dist:mac -- --publish=always
```

5. Run the older version (2.1.0) - it should detect 2.1.1

### Testing with dev-app-update-yml

Create `dev-app-update.yml` in project root:

```yaml
owner: YOUR_USERNAME
repo: Narrowcasting
provider: github
```

Then in development:
```bash
export ELECTRON_IS_DEV=0
npm start
```


## Best Practices

1. **Semantic Versioning**: Use proper version numbers (MAJOR.MINOR.PATCH)
2. **Release Notes**: Always include changelog in GitHub releases
3. **Beta Channel**: Use prerelease for testing updates
4. **Staged Rollout**: Release to small group first
5. **Rollback Plan**: Keep previous versions available
6. **Auto-Update Disable**: Add option in settings to disable auto-updates
7. **Update Schedule**: Check for updates at app startup, not too frequently
8. **Delta Updates**: electron-updater supports differential updates (only download changes)

## Troubleshooting

### Updates not detected
- Check network connectivity
- Verify update server URL
- Check electron-log for errors: `~/Library/Logs/Narrowcast Pro/main.log`

### Update fails to install
- Check write permissions
- Verify update signature
- Try manual installation

### Code signing required (Mac)
For auto-updates on Mac, you need code signing:
```bash
npm run dist:mac -- --publish=always
```

With signing certificate:
```json
{
  "build": {
    "mac": {
      "identity": "Developer ID Application: Your Name (TEAM_ID)"
    }
  }
}
```
